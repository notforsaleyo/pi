# 세션 아카이브

Pi 1.4.0의 `SessionSelectorComponent`를 재사용합니다.
목록 제목과 체크박스는 이 확장에서 생성한 목록 인스턴스에만 적용합니다.
pi 본체, 기존 `/resume`, Ctrl+S 키 설정은 변경하지 않습니다.
추가 후 `/reload`하거나 pi를 재시작하여 적용합니다.

## 사용법

| 조작 | 결과 |
|---|---|
| `/archive` -> Enter | 체크한 세션을 일괄 보관합니다. 체크가 없으면 커서가 가리킨 하나를 보관합니다. |
| `/archive`에서 Ctrl+Space | 커서가 가리킨 세션의 체크를 켜거나 끕니다. |
| `/archive`에서 Ctrl+A | 현재 검색 결과 전체를 선택/해제합니다. 화면 밖 결과도 포함합니다. |
| `/show-archived` -> 선택 -> Enter | 일반 폴더로 복원한 뒤 재개합니다. |
| `/show-archived` -> 선택 -> Ctrl+U | 복원만 하고 현재 대화를 유지합니다. |
| Esc | 목록을 닫습니다. |
| Tab | 현재 작업 폴더 / 전체 폴더를 전환합니다. |

목록 제목은 각각 `Archive Sessions`와 `Archived Sessions`이며, 현재 폴더/전체 범위를 함께 표시합니다.
체크한 항목은 검색어나 폴더 범위를 바꿔도 유지합니다. 체크 상태와 전체 선택 개수를 표시합니다.
일괄 보관은 파일별로 처리하며 일부 실패해도 나머지는 계속합니다. 성공·실패 개수와 오류를 안내합니다.
응답 생성이나 도구 실행 중에도 목록 조회, 다른 세션 보관, 복원만 하기는 즉시 가능합니다.
Enter로 다른 세션을 재개할 때만 목록을 닫은 뒤 현재 작업이 끝나기를 기다립니다.

검색, 정렬, 경로 표시, 이름 필터, 이름 변경, 삭제 확인은 pi의 기존 목록 동작입니다.
Ctrl+U는 보관 목록의 일반 선택 상태에서만 복원 동작입니다.
이름 변경과 삭제 확인 중에는 복원하거나 다중 선택을 변경하지 않습니다.
복원 후 재개가 취소되거나 실패하더라도 파일은 일반 폴더에 남습니다.
이 경우 Ctrl+S에서 다시 열 수 있습니다.

## 저장 구조

`<agent-dir>`는 기본적으로 `~/.pi/agent`이며 `PI_CODING_AGENT_DIR`를 따릅니다.

```text
<agent-dir>/sessions/<encoded-cwd>/<filename>.jsonl
<agent-dir>/archived-sessions/<encoded-cwd>/<filename>.jsonl
```

이동할 때 폴더 구분, 파일명, 세션 ID, 파일 내용과 수정 시간을 유지합니다.
보관된 부모 세션의 경로는 목록 표시 시에만 변환하여 분기 관계를 보여줍니다.
JSONL에 기록된 원래 부모 경로는 수정하지 않습니다.
아카이브 폴더는 첫 보관 때 생성하며, 빈 목록 조회는 폴더를 생성하지 않습니다.
현재 저장소의 기본 제외 규칙과 `*.jsonl` 규칙으로 보관 대화도 Git에 포함되지 않습니다.

## 안전장치와 제한

- 현재 pi에서 열린 세션은 목록에서 제외하고, 이동 직전에도 검사합니다.
- **다른 pi 프로세스에서 열린 세션은 먼저 닫아야 합니다.**
  다른 프로세스의 모든 쓰기를 차단하는 전역 잠금은 제공하지 않습니다.
- 사용자 지정 `sessionDir`은 지원하지 않으며, 기본 폴더 구조만 이동합니다.
- 심볼릭 링크, 디렉터리 정션, 이미 하드 링크가 여러 개 있는 파일은 이동하지 않습니다.
- 대상 파일이 이미 있으면 덮어쓰지 않습니다.
- 같은 파일 시스템 안에서 배타적으로 하드 링크를 생성한 뒤 원래 경로를 제거합니다.
  Windows NTFS에서 검증했으며, 하드 링크 미지원 파일 시스템에서는 원본을 유지하고 실패합니다.
- 원래 경로 제거에 실패하면 새 경로 생성을 되돌립니다.
  프로세스 강제 종료나 되돌리기 실패 시 양쪽 경로가 남을 수 있으며,
  자동으로 덮어쓰거나 삭제하지 않습니다. 해당 상태는 수동 확인이 필요합니다.
- 이 기능은 목록 정리용입니다. 별도 디스크의 백업이나 읽기 전용 보관 기능은 아닙니다.

## 코드 구성

- `session-archive.ts`: 명령 등록과 보관·복원 실행을 담당합니다.
- `session-archive-selector.ts`: 목록 조회, 표시, 키 입력과 선택 상태를 담당합니다.
- `session-archive-store.ts`: 경로 검증과 안전한 파일 이동을 담당합니다.

## Pi 버전 호환성

Pi 1.4.0에는 제목 설정과 필터 결과 조회 API가 없어, `session-archive-selector.ts`에
목록 UI와 필요한 내부 상태 접근을 모았습니다. pi 본체나 전역 프로토타입은 수정하지 않습니다.
구조를 확인할 수 없는 버전에서는 화면 구성을 중단하고 오류를 알립니다.
Pi 업데이트 후에는 제목·검색·다중 선택·스크롤 동작을 다시 확인하십시오.

## 검증 기록

코드 정리 후 Pi 1.4.0과 Windows NTFS에서 자동 검증 37개를 통과했습니다.
임시 세션과 실제 pi 목록 컴포넌트로 제목, 다중 선택, 스크롤, 응답 중 조회,
복원·재개, 삭제·이름 변경, 충돌 방지, 부분 실패와 이동 실패 시 되돌리기를 확인했습니다.
실제 터미널을 띄우는 대신 키 입력과 렌더링을 직접 구동한 검증입니다.
검증 스크립트는 파일로 저장하지 않고 실행했으며, 임시 데이터도 정리했습니다.
