## 대화 배경
DAYLIGHT(Godot) 프로젝트의 OpenSpec change `actis-and-cues` 탐색 중, Len의 "만지기" 대상 선택 방식을 정하다가 사용자가 낸 UI 아이디어입니다. 시각적 형태는 actis-and-cues 범위 밖으로 정했습니다.

## 기억할 내용
사용자 아이디어:
- 현재 레일에 만질 수 있는 대상이 하나 이상 있으면 Len의 우측 상단에 반짝이는 점이 뜹니다.
- Len이 멈추면 점이 펼쳐지면서 대상들의 이름이 한 글자씩 쓰입니다. 대상이 하나여도 같은 방식입니다.
- up/down 누름으로 대상을 고르고, 상호작용 키(현재 space)로 발동합니다.
- Len이 움직이면 글자가 한 글자씩 사라지며 다시 점이 됩니다.

## 현재 결론과 미정 사항
- actis-and-cues에서 확정한 동작 규칙: 멈춰 있을 때만 목록이 열리고 선택할 수 있습니다. 움직이면 닫히고 선택도 사라지며, 움직이는 중의 상호작용 키는 아무 일도 하지 않습니다. 이 힌트 UI는 입력을 받지 않고 표시만 하며, up/down은 Len이 소유합니다.
- 범위 밖: 점, 글자 애니메이션 등 시각적 형태 전부.
- 미정: "멈춤"의 정의(좌우 키를 누르지 않음 / idle 동작 중)는 데모에서 비교해 정합니다. 목록 순서와 처음 선택되는 대상도 미정입니다.

## 다음에 이어갈 지점
actis-and-cues 이후, 힌트 UI(MasterSchema의 `ui/acti_hint`)를 만드는 change에서 이 형태를 기획 입력으로 씁니다.

## 참고
- 프로젝트: DAYLIGHT. 탐색 기록은 `openspec/changes/actis-and-cues/exploration.md` 3.9절과 7장.
